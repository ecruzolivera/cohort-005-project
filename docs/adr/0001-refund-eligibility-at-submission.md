# Evaluate refund eligibility at submission

Refund eligibility is evaluated using facts at the time the learner submits the Refund Request, rather than at Admin review time, so review delays and later learning activity cannot make a timely request ineligible. Preserve submission-time eligibility evidence separately from current activity; missing historical evidence is unknown and requires an internally documented Refund Exception to approve. This adds evidence storage and handling for older requests, but avoids judging a request using facts that changed while it waited for review.
