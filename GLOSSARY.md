# Cadence

Cadence is an online course platform where learners purchase courses and can request their money back.

## Language

**Refund request**:
A learner's request to have money returned for a course purchase, subject to review. A request can be approved or declined; submitting it does not mean money has been returned.
_Avoid_: Cancellation request, reversal, chargeback, refund (when referring to the request).

**Approved refund request**:
A refund request accepted by the team. Approval does not mean the money has been returned.
_Avoid_: Refund completed, completed refund (when only approval has occurred).

**Refund**:
Money returned to the purchaser for a course purchase.
_Avoid_: Cancellation, reversal, chargeback, refund request (when referring to money returned).

**Completed refund**:
A refund whose return of money has been confirmed.
_Avoid_: Approved refund request (when referring to the completed return of money).
